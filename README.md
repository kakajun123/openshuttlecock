# Open Shuttlecock

A free, open-source site that reads the feathers of a badminton shuttlecock from three photos and says how sure it is.

Site: https://openshuttlecock.com · [中文说明](README.zh-CN.md)

## What it does

- **Reads feathers from photos.** Three photos of one shuttlecock: the whole shuttle, the feathers parted, and one against the light. The reading describes feather shape, shaft, consistency, whiteness and visible defects, and gives a grade tendency from 1 to 5.
- **Says what it cannot know.** A photo does not show the inside of the cork, weight, speed, flight or durability. A reading never judges whether a shuttle is genuine and never names a maker or a brand.
- **Keeps an open knowledge base.** Plain articles about shuttlecock feathers, free to reuse with credit.
- **Answers questions.** An AI drafts the answer from the knowledge base, a person reviews it, then it is published.
- **Credits the factories that contribute.** Photos and process notes come with their source.

## Status

The site, the knowledge base and the question form are being prepared for launch. **Photo reading is not open yet.** It opens after it has been tested against a set of shuttlecocks with known grades.

Photo reading will not be available in mainland China, Hong Kong or Macau at first, because the AI service it relies on is not offered there.

## How it works

The project does not train a model. It sends the photos to Claude, an AI model made by Anthropic, together with an open reference library of graded examples. The reference library is the part that improves over time, and it is open.

## Run it locally

The site is generated by one script and has no dependencies. You need Node.js 22 or newer.

```bash
node build.mjs
```

```bash
node serve.mjs
```

Then open http://localhost:4173.

## Layout

| Path | What it holds |
| --- | --- |
| `build.mjs` | The static site generator. Writes the whole site to `dist/`. |
| `serve.mjs` | A local preview server for `dist/`. |
| `content/knowledge/` | Knowledge base articles, in Markdown, one folder per language. |
| `content/legal/` | Privacy policy and terms of use. |
| `src/i18n/` | Interface text, one JSON file per language. |
| `src/styles/`, `src/scripts/` | The stylesheet and the small script. |
| `src/assets/` | Photographs (with credits) and fonts. |
| `tools/check-i18n.mjs` | Checks every language file against `en.json`. |

## Languages

The interface is in English, Chinese, Malay, Indonesian, Thai, Japanese, Korean and Hindi. Articles and legal pages are in English and Chinese.

Six of the eight interface translations were made by AI and have not yet been checked by native speakers. Corrections are welcome: edit `src/i18n/<code>.json`, then run:

```bash
node tools/check-i18n.mjs
```

## Contributing

- **A bug in the site, or a wrong translation:** open an issue or a pull request.
- **A question about shuttlecocks:** use the question form on the site, so the answer can be reviewed and published.
- **A factory that wants to contribute photos or process notes:** see the "For factories" page on the site.

## Factory data contributors

## Who runs it

Open Shuttlecock was started and is run by Australia Lifeng Sports Goods Pty Ltd, the Australian company behind the SP x SPORT brand. SP x SPORT also sells shuttlecocks. For that reason the readings and articles recommend no brand, including ours.
