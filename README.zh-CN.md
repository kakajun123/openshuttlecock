# Open Shuttlecock

免费、开源的羽毛球毛片识别网站:三张照片看毛片,并告诉你有几分把握。

网站:https://openshuttlecock.com · [English](README.md)

## 它做什么

- **从照片识别毛片。** 同一颗球拍三张:整颗球、拨开毛片的近景、透光照。识别结果会说明毛片形状、毛杆、一致性、洁白度和可见缺陷,并给出一级到五级的档次倾向。
- **明说哪些看不出来。** 照片拍不到球头内部、重量、球速、飞行和耐打程度。识别不判断真伪,也不说出自哪家工厂、哪个品牌。
- **维护一个开放的知识库。** 关于羽毛球毛片的大白话文章,署名即可自由转载。
- **回答问题。** AI 依据知识库起草答案,人工审核后公开。
- **为贡献数据的工厂署名。** 照片和工艺资料都注明来源。

## 当前状态

网站、知识库和提问功能正在准备上线。**照片识别还没有开放**,要等用一批已知等级的羽毛球测试过之后才开放。

照片识别初期不对中国大陆、香港和澳门开放,因为它依赖的 AI 服务不在这些地区提供。

## 工作原理

项目不训练模型。它把照片交给 Anthropic 的 AI 模型 Claude,同时附上一份开放的、带等级的参考样例库。会不断改进的是这份参考库,而它是开放的。

## 本地运行

整个网站由一个脚本生成,没有任何依赖。需要 Node.js 22 或更高版本。

```bash
node build.mjs
```

```bash
node serve.mjs
```

然后打开 http://localhost:4173。

## 目录

| 路径 | 内容 |
| --- | --- |
| `build.mjs` | 静态网站生成脚本,把整个网站写到 `dist/`。 |
| `serve.mjs` | 预览 `dist/` 的本地服务器。 |
| `content/knowledge/` | 知识库文章,Markdown 格式,每种语言一个文件夹。 |
| `content/legal/` | 隐私政策和使用条款。 |
| `src/i18n/` | 界面文字,每种语言一个 JSON 文件。 |
| `src/styles/`、`src/scripts/` | 样式和脚本。 |
| `src/assets/` | 照片(附署名)和字体。 |
| `tools/check-i18n.mjs` | 把每个语言文件和 `en.json` 对照检查。 |

## 语言

界面有英文、中文、马来文、印尼文、泰文、日文、韩文、印地文八种。文章和法律页面只有英文和中文。

八种界面语言里有六种是 AI 翻译的,还没有母语者核对。欢迎纠正:修改 `src/i18n/<语言代码>.json`,然后运行:

```bash
node tools/check-i18n.mjs
```

## 参与

- **网站故障或翻译错误:** 提 Issue 或 Pull Request。
- **关于羽毛球的问题:** 请用网站上的提问表单,这样答案可以经过审核再公开。
- **工厂想提供照片或工艺资料:** 请看网站上的"工厂合作"页面。
